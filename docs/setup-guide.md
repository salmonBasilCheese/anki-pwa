# iPhone への導入手順

家族の iPhone に anki-pwa を入れて、デッキを取り込み、毎日使えるようにするまでの手順です。
大人が子どもの iPhone を手に取って、上から順に進めます（所要時間の目安: 10〜15 分）。

- 安定版の URL: https://salmonbasilcheese.github.io/anki-pwa/
- 子どもの iPhone には **安定版だけ**を入れます。末尾が `/dev/` の開発版は入れません。
- 学習記録は、その iPhone の中だけに保存されます（サーバーには送られません）。

## 用意するもの
- 取り込むデッキのファイル（`.apkg`）。別の端末から AirDrop で送れる状態にしておく
- iPhone の空き容量（デッキ 1 つにつき、数十 MB 程度）
- iOS の標準アプリ「Safari」「ファイル」「リマインダー」（最初から入っています）

## 1. ホーム画面に追加する
1. **Safari** で、安定版の URL を開きます（他のブラウザではなく Safari を使います）。
2. 画面下の **共有ボタン**（四角から矢印が出ているマーク）を押します。
3. 一覧を下にスクロールして **「ホーム画面に追加」** を押します。
4. 名前が「Anki」になっていることを確認して **「追加」** を押します。
5. ホーム画面にできたアイコンから開きます。**以後は、このアイコンから使います**（Safari では開きません）。

> アイコンから開いたとき、上に URL の欄が出ていなければ、正しく追加できています。

## 2. デッキを取り込む
1. 別の端末から、`.apkg` のファイルを **AirDrop** で子どもの iPhone に送ります。
2. 受け取ったら、保存先に **「ファイル」アプリ**（「このiPhone内」など）を選んで保存します。
   画面の表示が違うときは、共有メニューから「"ファイル"に保存」を選びます。
3. ホーム画面のアプリを開き、**「ファイルを選択」**（またはその下の取り込みボタン）を押して、
   「ファイル」アプリに保存した `.apkg` を選びます。
4. 取り込みが終わると、そのまま学習画面が開きます。左上のボタンで一覧に戻ると、
   「保存済みデッキ」に載っています。

> 取り込み済みのデッキを入れ直すと、「置き換えますか？」と聞かれます。置き換えても、
> 同じデッキなら学習記録と設定は引き継がれます。

## 3. 子ども向けの設定を確認する
一覧のデッキの **「設定」** ボタンを押すと、次の項目があります。

| 項目 | 内容 | 子ども用の目安 |
|---|---|---|
| 新規カード/日 | 1 日に新しく覚える枚数 | 最初は少なめ（例: 5〜10）にして、慣れたら増やす |
| IPA（発音記号）を表示する | 裏面に発音記号を出すか | 子どもには、チェックを **外す** |
| 文字サイズ | カードの文字の大きさ | 読みにくければ「大」にする |
| 表示する項目を選ぶ | 表面・裏面に出す項目 | 通常は触らない（形式の違うデッキを開くときに使う） |

設定はデッキごとに、その iPhone の中に保存されます。

## 4. 毎日の通知を設定する（標準「リマインダー」）
このアプリは通知を出しません。iPhone 標準の「リマインダー」で、毎日の合図を作ります。

1. **リマインダー**アプリを開き、**「新規」**（左下の「＋」）を押します。
2. タイトルを「単語学習」などにします。
3. **（i）ボタン**から、**日付**と**時刻**を、学習したい時間（例: 夕食の前）にします。
4. **「繰り返し」** を **「毎日」** にします。
5. 通知を許可していなければ、「設定」→「通知」→「リマインダー」で通知を許可します。

## 5. 毎日の使い方
- ホーム画面のアイコンから開きます。
- 一覧の上に **連続学習日数**、各デッキに **今日の残り枚数** が出ます。「今日の分は完了」と出れば、その日は終わりです。
- 「開く」を押し、カードを見て、答えを思い出したら画面をタップして答えを見ます。
  思い出せた度合いに合わせて、4 つのボタン（もう一度 / 難しい / 正解 / 簡単）から選びます。

## 6. バックアップを取る（月に 1 回程度）
iPhone を機種変更したり、アプリを消したりすると、学習記録も消えます。定期的に控えを取ります。

1. 一覧の下の **「バックアップ」** で **「書き出す」** を押します。
2. 共有画面で **「ファイルに保存」** を選び、保存します。
3. 「最後のバックアップ: ○日前」の表示で、前回からの日数を確認できます。
4. 記録を戻すときは、**「読み込む」** で、保存したファイルを選びます。
   確認画面で内容を見てから反映されます（新しいほうの記録が残ります）。

> 機種変更のときは、新しい iPhone に先に `.apkg` を取り込んでから、バックアップを読み込みます。

## 7. 困ったとき
| 症状 | 対処 |
|---|---|
| 「新しいバージョンがあります」と出る | 「更新」を押します。出ないときは、アプリを一度完全に閉じて開き直します |
| 画面の下や上が見切れる | アプリを完全に閉じて、開き直します |
| デッキが開けない（項目がありません） | デッキの「設定」→「表示する項目を選ぶ」で、表面・裏面に出す項目を選びます |
| デッキや記録が消えた | バックアップがあれば、「読み込む」で戻します。ブラウザ（Safari）でなくホーム画面のアイコンから使っているか確認します |
| 音が出ない | 本体の音量と、イヤホンなどの接続を確認します。カードの音声ボタンが薄い表示なら、そのカードには音声が入っていません |

## 大人が覚えておくこと
- 記録は **その iPhone の中だけ**にあります。端末間の同期はありません。
- アプリは、ホーム画面のアイコンから使い続けてください。Safari のタブで開いたままだと、
  しばらく使わないときに保存データが消えることがあります。
- 更新は、アプリを開いたときに自動で知らせます。大人が定期的に「更新」が出ていないかを見てあげてください。
- 開発版（`/dev/`）は、別のアイコン（紫）・別の保存先です。誤って子どもの iPhone に入れないでください。
